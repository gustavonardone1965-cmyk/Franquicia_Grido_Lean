# Franquicia_Grido_Lean

Proyecto Lean en franquicias de Grido

Instrucciones rápidas:
- Coloca en la raíz: index.html, manifest.json, sw.js, App.jsx, grido_lean.png, carpeta icons/ con icon-192.png y icon-512.png.
- Publica con GitHub Pages (rama main o gh-pages).
- Abre la consola del navegador si algo falla (DevTools → Console y Application → Service Workers).
